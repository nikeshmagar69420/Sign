# Hand Gesture Demo

This project uses the camera to detect hand signs and then responds with voice, text, and sound.

## What it does

- Open the webcam
- Detect different hand gestures
- Match each gesture to a response
- Speak a phrase or play a sound
- Show special effects for some actions

## Hand signs

- Open palm = Hello!
- Peace sign = Hi!
- Thumbs up = I am doing great!
- Pointing finger = My name is [your name]
- Closed fist = Thank you!

## Special actions

- Two peace signs together = Miku sound and special reaction

## Notes

- Allow camera access in the browser
- Use a browser that supports webcam access
- Sound may need a click before it plays

## Simple explanation

This project shows how a computer can understand hand movements using a camera and machine learning. It is a fun example of AI and human-computer interaction.
